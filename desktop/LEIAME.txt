ELDVAR - versao para PC

A) Gerar o instalador (.exe):
   1. Instale o Node.js (https://nodejs.org)
   2. Dois cliques em INSTALAR.bat
   3. O instalador "Eldvar Setup ... .exe" (e uma versao portatil) aparece na pasta release

B) Só jogar agora: dois cliques em JOGAR_SEM_INSTALAR.bat

Atualizar o jogo: troque app/index.html pelo novo eldvar.html (renomeado) e rode INSTALAR.bat de novo.
F11 = tela cheia. Precisa de internet para contas/ranking/boss mundial.

== VERSÃO COMPLETA (launcher) ==
Ao abrir o Eldvar aparece o Launcher: mostra a versão instalada/online, as novidades,
botão "Atualizar jogo" (baixa a versão mais nova do GitHub), "JOGAR" e opção de atualizar
automaticamente. Criar conta / Entrar: clique em JOGAR e use as opções na tela inicial do jogo.
Sem internet você ainda joga a versão instalada.
Para o dev: após cada build rode `node desktop/mkver.mjs` e envie public/index.html + public/version.json.

== ATALHO NA AREA DE TRABALHO ==
- Instalador (INSTALAR.bat -> release\Eldvar Setup.exe): cria o atalho "Eldvar" na Area de Trabalho automaticamente.
- Sem instalar: dê 2 cliques em CRIAR_ATALHO.bat (ou JOGAR_SEM_INSTALAR.bat, que também cria) — aparece o atalho "Eldvar".
